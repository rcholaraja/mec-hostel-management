# How to Run MEC Hostel Management System

Follow these simple steps to run the application on your Windows computer.

## 1. Install Java
You need Java installed to run this application. 
- Download and install **Java 17 JDK** from here: [Oracle JDK 17 Download](https://www.oracle.com/java/technologies/downloads/#java17) (Choose the **x64 Installer**).

## 2. Download the App
1. Go to the [GitHub Repository](https://github.com/rcholaraja/mec-hostel-management).
2. Click the green **Code** button and select **Download ZIP**.
3. Extract the ZIP file to a folder on your computer.

## 3. Run the Application
1. Open the extracted folder and navigate to `backend/`.
2. Double-click the file named `run_app.bat`.
3. Wait for the terminal to show "Started HostelManagementSystemApplication".
4. Open your browser and go to: **http://localhost:8080**

---
*Note: If `run_app.bat` doesn't work, you can open a terminal in the backend folder and type:*
`mvnw spring-boot:run`
