# MEC Hostel Management System

A full-stack hostel management application with a Spring Boot backend and a React (Vite) frontend.

## Project Structure
- **/backend**: Spring Boot application (Port 8080)
- **/frontend**: React + Vite application (Port 5173)

## Features
- Student Registration & Records
- Daily Attendance Tracking
- Leave, On-Duty, and Outing Request Management
- Warden Approval Dashboard
- Attendance Reporting

## Getting Started

### Backend
1. Navigate to `backend/`
2. Run `mvn spring-boot:run`

### Frontend
1. Navigate to `frontend/`
2. Run `npm install`
3. Run `npm run dev`
